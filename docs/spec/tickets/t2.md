# t2 — `delta-capture`（GDI 小区域高速截屏）

**独占写锁**：`crates/capture/**`
**依赖**：t1
**规格**：`../spec.md`（§2.1 `core/capture.py:29` 行，§6 黑帧风险）

## 任务
1. 进程级 Per-Monitor V2 DPI 感知：在**任何 GetDC 之前**完成（用 `SetProcessDpiAwarenessContext` 优先，失败回落 `SetProcessDpiAwareness(2)`，再回落 `SetProcessDPIAware`）。
2. `Capturer` 结构：**常驻**兼容 DC + DIB Section 位图，按最大区域尺寸预分配；同一区域重复抓取时复用位图，不重复 CreateCompatibleBitmap。
3. `pub fn grab(&mut self, rect: PxRect) -> Result<Frame, CaptureError>`：
   - `BitBlt` 从屏幕 DC 拷贝到内存 DC；
   - `GetDIBits` 取 32bpp top-down BGRA 到 `Vec<u8>`；
   - 返回 `Frame { w, h, stride, data: Vec<u8>, captured_at: Instant }`。
4. `Frame` 提供 `luma(&self) -> GrayImage`（BT.601 整数近似 `(77r+150g+29b)>>8`），避免浮点。
5. **黑帧检测**：`Frame::is_black(threshold_pct)`（默认 99.5% 像素 luma<8）—— 用于识别独占全屏导致的全黑，返回 `CaptureError::BlackFrame`，附建议文案「请把游戏切换为无边框窗口模式」。
6. 失败必须留证：`CaptureError` 保留 Win32 错误码（`GetLastError`）。
7. 单元测试：给定合成位图，验证 `grab` 的 stride/通道顺序/luma 换算；黑帧检测的边界（99.4% 黑 → 不触发，99.6% → 触发）。
8. 提供一个 `#[ignore]` 的真实抓屏测试（手动运行），抓 100x100 区域 100 次计时，断言均值 <1ms。
