# t9 — `delta-ui` + `delta-app`（界面、校准向导、打包）

**独占写锁**：`crates/ui/**`、`crates/app/**`、`assets/**`、`build.rs`
**依赖**：t7、t8
**规格**：`../spec.md`（D1、D6、D9、D11，§4 体积与单实例门禁）

## 任务

### delta-ui（设计 token 来自玲珑的规范）
1. 深色工装仪器风主窗口：视口尺寸 360×240（收起态 360×44），无边框（`with_decorations(false)`），置顶。
2. 颜色/圆角/间距全部走 `ui::theme` 常量表，**禁止在控件里散写魔法数**。主色与状态色必须与玲珑给的 token 一致（深色底 `#B4BCC8` 正文、成功/警告/危险三色）。
3. 主界面信息架构：顶部状态条（当前场景 + 置信度）→ 目标序列显示区（操作台时显示 4 组）→ 三个功能入口（摩斯/指纹/操作台，未校准则灰置并显示「未校准」）→ 底部「一键识别 F8」主按钮 + 设置齿轮。
4. **五态视觉**：`空闲 / 运行中 / 成功 / 失败 / 超时`，用边框呼吸（运行中）、色块（成功绿 / 失败红 / 超时琥珀）区分；运行中窗口不抢焦点、不遮挡游戏（可用穿透点击区域仅在按钮上）。
5. 中文渲染：内嵌 `assets/fonts/` 下的**单 face TTF**（不要用 `msyh.ttc`，epaint 只取 face 0 会踩坑）；构建后首帧自检，缺字则回退系统字体并记录。
6. 托盘或最小化：v1 允许「最小化到任务栏 + 全局热键唤出」，不做托盘（避免额外依赖）。

### 校准向导（D9）
7. 独立的校准模式窗口：进入后游戏画面上一层层叠加半透明遮罩 + 可拖拽框选控件（egui `Area` + 自绘）。
8. 步骤流（每步一个动作，可回退、可跳过）：
   1) 选屏幕（当前仅主屏，显示分辨率）
   2) 框选摩斯 3 区（可只框 1 个，缺的流程灰置）
   3) 框选指纹：人名区 / 数字区 / 9 个候选格（点 4 角自动生成格子，或逐个拖）
   4) 框选操作台：LED 区 / 面板区 / 4 条列线 / 4 条行线 / 旋钮中心
   5) 预览验证：当场截屏回显，把框画上去，用户确认
   6) 保存（百分比，原子写）
9. 每一步有「实时回显」：拖动时立刻重抓该区域并在小窗里显示，用户能肉眼确认框对不对。
10. 支持「补录指纹模板」：截图 9 格 + 填角色名 → 存进 `images/<角色>/`（解决模板过期风险）。

### delta-app
11. 单实例：命名互斥量（`CreateMutexW`），第二个进程激活已有窗口后退出。
12. 主循环：热键事件 → `scene::detect` → 分发到对应 flow → 结果回 UI（全程不阻塞 UI 线程，用 `std::thread` + `mpsc`）。
13. ~~首次启动弹免责声明（D12），确认后写 `accepted_disclaimer`。~~ **已废弃（2026-11-09 用户决策）**：免责声明与 `accepted_disclaimer` 字段全部移除，启动直达主界面。
14. 打包：`crates/app/build.rs` 用 `embed-resource` 内嵌 `assets/icon.ico`（7 尺寸）作为 exe 图标；窗口图标走 `egui::IconData`（运行期解码 `assets/icon.png`）。`cargo build --release` 后产物体积断言 ≤12MB。

## 禁止
- 不要引入 `wgpu` 后端（D1 已定 glow）。
- 不要引入 `tauri`/`iced`/`slint`（体积与工期都不划算）。
- 不要在 UI 线程里跑识别（必须后台线程 + 消息回传）。
- 禁止 `// TODO` 或「其余不变」类占位；未实现的功能要么完整实现，要么灰置并在代码里写明 Non-Goal 依据。
