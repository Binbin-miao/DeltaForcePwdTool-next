# t3 — `delta-vision`（手写 NCC + 轮廓 + 点阵字符）

**独占写锁**：`crates/vision/**`
**依赖**：t1
**规格**：`../spec.md`（§2.1 `core/fingerprint.py:86-96`、`core/morse.py:24-55`，§2.2 不变量 7）

这是整个项目的性能底座，**不允许为了"差不多"而牺牲正确性**。

## 任务
1. `GrayImage { w, h, data: Vec<u8> }`：`from_frame`、`crop`、`resize_bilinear`、`resize_to`。
2. **Otsu 二值化**：直方图 256 bin，返回 `(threshold, BinaryImage)`；`BinaryImage` 位打包（`Vec<u64>`）以省内存。
3. **轮廓提取**：8 连通外轮廓 + `bounding_rect`，**语义与 OpenCV `RETR_EXTERNAL` + `CHAIN_APPROX_SIMPLE` 对齐**（外层轮廓、不返回洞）。用并查集或扫描线连通域实现，禁止用递归 flood fill（栈溢出）。
4. **手写 NCC 模板匹配**（核心）：
   - `match_template_ncc(image: &GrayImage, tmpl: &GrayImage) -> (best_x, best_y, best_score)`；
   - 公式严格等价 `TM_CCOEFF_NORMED`：
     `score = Σ(I-Ī)(T-T̄) / sqrt(Σ(I-Ī)² · Σ(T-T̄)²)`，零方差时返回 0.0（不得 NaN）；
   - 用**积分图和平方积分图**把窗口 `ΣI`、`ΣI²` 做成 O(1)，模板侧 `T̄`、`Σ(T-T̄)²` 预计算；
   - 滑动窗口内层循环用 `f32`，禁止逐步 `powi`；
   - 必须与 OpenCV 结果在同一输入上差异 <1e-4（写测试时用固定合成数据 + 预存的 OpenCV 参考值）。
5. **点阵字符读取**（给 LED 目标序列用）：输入一张 LED 区域灰度图，切分字符格（按列投影找间隔），逐格与 `0`/`1`/`-` 三个内嵌模板做 NCC，返回 `Result<String, VisionError>`。字符集仅 `0`,`1`,`-`。
6. **斜纹遮蔽检测**（操作台完成判据）：给定面板区域，统计 45° 方向梯度能量 + 黄黑交替行数，返回 `bool`。阈值通过配置暴露，默认值由合成图测试锁定。
7. 基准与测试：
   - 单元测试全部算法（含零方差、全黑、单像素等退化输入）；
   - `#[ignore]` 基准：105x105 模板在 105x105 图上匹配 1000 次，断言 <40ms（即 612 次组合 <25ms 的余量）。

## 验收

```bash
cargo test -p delta-vision

```

## 禁止
- 不要用 `imageproc` 的 `match_template`（浮光结论：无 CCOEFF 变体，语义不等价）。
- 不要引入 OpenCV 绑定。
- 不要实现业务逻辑（认角色、点击），只做纯图像函数。
