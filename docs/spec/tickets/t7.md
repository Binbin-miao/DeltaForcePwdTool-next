# t7 — `delta-scene` + `flow-morse` + `flow-fingerprint`

**独占写锁**：`crates/scene/**`、`crates/flow-morse/**`、`crates/flow-fingerprint/**`
**依赖**：t2、t3、t4、t5、t6
**规格**：`../spec.md`（D2、D3、D5、D6、D10，§2.2 全部 10 条不变量，§4 场景判别门禁）

## 任务

### delta-scene（一键场景判别，D6）
1. `detect(frame: &Frame, cfg: &Config) -> SceneVerdict`，返回 `{ scene: Scene, confidence: f32, scores: [f32;3] }`，`Scene = Morse | Fingerprint | Console | Unknown`。
2. 三路结构特征打分（**必须用结构特征，不能用整屏模板匹配**，否则分辨率一变就废）：
   - **Morse**：3 个摩斯区域内「白色高亮像素占比」+ 轮廓数量与点划特征（`aspect>2` 的长条数 ≥1 且总数 ≥3）。
   - **Fingerprint**：9 个候选框内平均边缘密度（Sobel 幅度均值）是否显著高于空白格；且 `name_region` 有文字笔画密度。
   - **Console**：`led_region` 内亮点占比 + 竖直投影是否能切出 ≥7 个字符格；`panel_region` 内是否存在 4 条等距竖列的高亮标记。
3. **判别规则**：最高分 > `0.6` 且与次高分差 > `0.15` → 采纳；否则 `Unknown`。
4. **Unknown 必须拒绝执行**（D6 硬约束），返回明确原因字符串供 UI 显示。
5. 单元测试：用 `_upstream` 的真实截图（摩斯/指纹）+ 视频抽帧（操作台）+ 桌面截图，断言四种判定；**桌面截图必须判 `Unknown`**。

### flow-morse
6. 复刻 `morse.py`：3 区截图 → `vision::otsu` + `contours` → `w*h<10` 过滤 → `aspect>2.0` 判划（`==2.0` 判点）→ 按 x 升序拼接 → 查 `MORSE_TABLE`。
7. **三态错误**（不许压成 `"?"`）：`Empty`（无轮廓）/ `Unmapped`（长度或组合不在表内）/ `Error`。三态都输出 `?` 给用户，但日志与返回值可区分。
8. **保留非对称副作用**（spec §2.2 第 5 条）：任一格失败 → 仍然敲出已成功的数字键，仅跳过确认点击。
9. 时序：按键间隔 50ms；全部成功且 `confirm_clicks` 非空 → 等 600ms → 依次点击（间隔 100ms，与 `morse.py:105` 一致）。

### flow-fingerprint
10. 流程：截全屏 → 裁 `name_region` → **先走模板投票**（`templates::vote_role`）→ 若 `Ambiguous` 或投票失败且 `ocr_enabled` → `ocr::recognize` + 两级纠错（精确映射 `{"克菜尔":"克莱尔"}` + `difflib` 等价实现：字符交集占比 ≥0.6）。
11. `N` 取角色的模板张数（D3）。若同时读到了数字区域（可选，`ocr_enabled`），`max` 与 `N` 不一致时**以 N 为准并 warn**；读不到数字属正常路径，不报错。
12. 存活格数 = `N+1`（`candidate_boxes` 行主序前 N+1 个）；`templates::assign` 得到 N 对 → **按模板号升序**点击各格中心。
13. `auto_click=false` → 只产出标注图（在 `Frame` 上画框 + `候选X→模板Y` 文本），不点击。
14. `confirm_clicks` 非空 → 点击完成后等 1700ms → 依次点击（间隔 50ms）。
15. 失败必留证：保存失败截图到 `logs/fail_<ts>.png` + 结构化原因（D10 缺陷③）。
