# t4 — `delta-templates`（角色库 + 全模板投票 + 二分图最大权匹配）

**独占写锁**：`crates/templates/**`
**依赖**：t1、t3
**规格**：`../spec.md`（D3、D4、D5，§2.1 fingerprint 行，§4 指纹离线复现门禁）

## 任务
1. `RoleLibrary`：扫描 `images/<角色>/<1..N>.png`，加载为灰度 `GrayImage`。
   - 每个角色的 `N` = 该目录下**连续编号图片的最大编号**（不是目录里文件数，防止 1,3,5 这种洞被误判）。
   - 记录 `Role { name, n, templates: Vec<(u32, GrayImage)> }`。
   - 加载失败的单张图跳过并 warn，全部失败才报错。
2. `match_cell(cell: &GrayImage, tmpl: &GrayImage) -> f32`：
   - **必须保留上游语义**：模板非等比 resize 到候选尺寸 → 取中心 70%×70% 作为模板核心 → 核心在候选图上做 NCC 取最大值。
   - 这是跨分辨率可用的根因（`fingerprint.py:86-96`），禁止改成等比缩放或整图匹配。
3. `vote_role(cells: &[GrayImage], lib: &RoleLibrary) -> Voted`：
   - 对**每个角色**，用该角色的全部模板与全部存活格做 NCC，得到 score 矩阵；
   - 角色得分 = 该角色矩阵的最大权匹配总分的**归一化值**（除以 N，避免模板多的角色占便宜）；
   - 返回 `Voted { role: &Role, score: f32, per_cell: Vec<(cell_idx, tmpl_idx, f32)> }`。
   - **置信度门**：最高分与次高分之差 <0.05 → 返回 `Ambiguous`（交给 OCR 兜底），不得硬选。
4. `assign(cells, role) -> Vec<(cell_idx, tmpl_no)>`：二分图最大权匹配（匈牙利，N ≤ 8，O(n³) 手写即可），要求：
   - 每个模板号恰好用一次；
   - 若最优解中某条边分数 < `min_score`（默认 0.45），该模板视为**未匹配**并在结果中标记，供上层告警（不得静默丢）。
5. 性能：612 次匹配（9 格 × 68 模板口径）必须走 `rayon` 并行 + 模板按候选尺寸的**预缩放缓存**；`#[ignore]` 基准断言 <40ms。
6. 离线回归测试（关键门禁）：用 `_upstream/images` 的真实 54 张模板 + 合成"候选格子"（直接把某角色模板加上噪声/缩放 0.8 倍当候选），断言：
   - 投票结果 = 该角色，且 `N` = 该角色模板张数；
   - `assign` 返回 N 对且模板号互不重复。

## 禁止
- 不要把 `match_threshold` 配置当阈值用（上游死配置，见 spec §2.2 第 10 条）。
- 不要在此 crate 里做截图或点击。
- 不要为了省事用贪心匹配（必须最大权匹配，D4 已拍板）。
