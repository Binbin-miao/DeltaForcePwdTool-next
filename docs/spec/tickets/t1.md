# t1 — workspace 骨架 + `delta-geom` + `delta-config`

**独占写锁**：`Cargo.toml`、`Cargo.lock`、`rust-toolchain.toml`、`crates/geom/**`、`crates/config/**`
**依赖**：无
**规格**：`../spec.md`（D1、D9、D10，§2.1 的 `utils/config.py:44-123` 行，§4 配置门禁）

## 任务
1. 建立 Rust workspace，成员为 t2~t9 列出的全部 crate（先各建 `lib.rs` 空壳 + 最小 `Cargo.toml`，不含实现）。
2. 根 `Cargo.toml` 写入体积优化 profile（浮光结论）：`opt-level="z"`、`lto="fat"`、`codegen-units=1`、`panic="abort"`、`strip=true`。
3. `delta-geom`：
   - `PctRect { x, y, w, h }`（0.0~1.0）与 `PxRect { x, y, w, h }`（i32 物理像素）双向换算，入参为 `MonitorInfo { w, h }`。
   - `PctPoint`/`PxPoint` 同理。
   - 换算必须**四舍五入到整数像素**且**幂等**：`px→pct→px` 在同一分辨率下必须完全还原（浮点误差用 `round` 吸收）。
   - 提供 `clamp` 到屏幕边界，越界返回 `GeomError::OutOfScreen` 而非静默裁剪（裁剪仅在校准 UI 显式请求时发生）。
4. `delta-config`：
   - 配置结构含：`monitor`(w,h)、`regions`(摩斯 3 区 `PctRect` + name)、`fingerprint`(name_region/number_region/candidate_boxes[9])、`console`(led_region、panel_region、col_x[4]、row_y[4]、knob_center)、`confirm_clicks`、`hotkeys`、`timings`、`accepted_disclaimer`、`ocr_enabled`。
   - **原子写**：写临时文件 → `File::sync_all()` → `fs::rename`。禁止直接覆盖。
   - **只存百分比**：`save()` 序列化 `PctRect`；`load()` 产出独立的 `PxView`，**绝不允许把像素值回写进配置结构**（这是上游重复 load 坐标漂移的根因）。
   - 缺失字段走默认值，未知字段忽略（前向兼容）。
   - `validate()` 返回缺失的必填区域清单（供 UI 灰置按钮用）。
5. 单元测试：幂等换算、100 次连续 `load()` 不漂移、越界返回错误、原子写在模拟写失败时不破坏原文件。
