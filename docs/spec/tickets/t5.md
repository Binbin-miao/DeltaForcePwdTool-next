# t5 — `delta-input` + `delta-hotkey`

**独占写锁**：`crates/input/**`、`crates/hotkey/**`
**依赖**：t1
**规格**：`../spec.md`（D8、D12，§2.1 `utils/mouse.py:56-71` 与 `main.py:82-90` 行）

## 任务
### delta-input
1. `click(x, y)`：`SendInput` 投递 `LEFTDOWN` + `LEFTUP`（各 1 事件，`dwExtraInfo` 统一填自定义标记），按下与抬起之间 `sleep(50ms)`（与上游一致）。
2. `click_all(&[(i32,i32)])`：串行投递，间隔默认 50ms。
3. **拖动（核心，D8）**：
   ```rust
   pub struct Drag { /* 内部维护按键状态 */ }
   impl Drag {
       pub fn begin(&mut self, at: PxPoint) -> Result<()>;      // 移动到起点 + LEFTDOWN
       pub fn step(&mut self, dx: i32, dy: i32) -> Result<()>;   // 相对移动，内部拆成 ≤20px 的子步，子步间 2ms
       pub fn end(&mut self) -> Result<()>;                      // LEFTUP
   }
   ```
   - 全部用 `MOUSEEVENTF_MOVE`（**相对**），`dx/dy` 为相对位移；**每步 ≤20px**（浮光结论：大跳在 Delta Force 里会被丢）；
   - 绝不允许使用 `MOUSEEVENTF_ABSOLUTE` 做拖动；
   - 提供 `Drop` 实现，确保异常路径也会 `LEFTUP`（防止键卡住）。
4. `key_digit(d: char)`：投递数字键 `0`~`9` 的 `SCANCODE`（`KEYEVENTF_SCANCODE`），不用 VK。
5. 输入事件计数：`static COUNTER: AtomicU32` 记录发出的所有事件总数，供测试断言「完成后零输入」。
6. 单元测试：合成一次拖动，断言事件序列为 `DOWN → MOVE×k → UP`，且每步 `|dx|,|dy| ≤ 20`；`Drop` 路径也会发 `UP`。

### delta-hotkey
7. 独立线程跑 `RegisterHotKey`（`MOD_NOREPEAT`，默认 `VK_F8`，可配置）+ `GetMessageW` 消息循环，命中后投递到 `mpsc::Sender<HotkeyEvent>`；**不需要管理员权限**。
8. 提供 `Hotkeys::register(key) -> Result<()>` / `Drop` 自动 `UnregisterHotKey`；注册失败（已被占用）返回明确错误码，不得静默。
9. 支持同时注册多个键（v1 只需一个「一键识别」，但接口保留多键）。
10. 单元测试：注册 → 模拟投递 → 收到事件；重复注册同键返回 `AlreadyRegistered`。

## 验收
```bash
cargo test -p delta-input -p delta-hotkey
cargo clippy -p delta-input -p delta-hotkey -- -D warnings
```

## 禁止
- 不要用 `enigo`（体积大）；不要用 `global-hotkey`（浮光建议自建线程更可控）。
- 不要在此 crate 里读屏幕或做判断。
- 禁止在拖动中途 `SetCursorPos`（会和相对移动打架）。
