# 三角洲密码助手 · Rust 重构版

《三角洲行动》骇客电脑解谜辅助工具。**只读屏幕 + 模拟键鼠**，不读写游戏内存、不修改任何游戏文件。

由 Python 版 [`Binbin-miao/DeltaForcePwdTool`](https://github.com/Binbin-miao/DeltaForcePwdTool) 重写而来：
去掉微信 OCR 依赖，体积从 PyInstaller 打包的 60MB+ 降到 **5.25MB 单文件**，
窗口 **0.05 秒出现**、约 **0.25 秒可操作**（独立四测中位数 47ms / 235ms）。

---

## 三步上手

1. **双击 `delta-pwd-tool.exe`** → 会弹 UAC 要管理员权限，点「是」（**必须**，见下）
2. **开游戏，按 `F8`** → 程序自动判断你当前在哪个小游戏界面，然后自己完成

> 启动直接进主界面，没有免责声明弹窗。

> **不需要校准**。坐标是内置的（2K 基准百分比），按你的分辨率自动换算，
> 1920×1080、2560×1440 都能直接用。只有当游戏大版本改了 UI 布局、或者你调了
> 游戏内 UI 缩放比例时，才需要进「校准向导」微调一遍。
>
> **为什么要管理员**：游戏通常以管理员身份运行，Windows 会静默丢弃低权限进程
> 发往高权限窗口的模拟点击 —— 表现就是「点了没反应」。程序启动时会自动请求提权。

## 它能做什么

| 场景 | 触发 | 它替你做的事 |
|---|---|---|
| **摩斯码** | `F8` 自动 / `F5` 强制 | 读三个摩斯格 → 解码成三位数字 → 自动敲键盘 → 点确认 |
| **指纹识别** | `F8` 自动 / `F6` 强制 | 认角色 → 匹配 9 个候选指纹格 → 按编号顺序自动点击 |
| **操作台旋钮（BETA）** | `F8` 自动 / `F7` 强制 | 读右上 LED 目标序列 → 按住旋钮左右切列、上下调值 → 对准后停住 → 4 列全对自动停手 |

`F8` 是「一键识别」：程序自己看当前是哪个界面，你不用记多个键。
如果判断不出去（比如你人在桌面），它会**直接拒绝执行**并提示，绝不会乱点。

> 操作台功能标 **BETA**：失败时会自动把截图和日志存进 `logs/`（`console_fail_*.png` / `.txt`），
> 拿这两份文件就能定位卡在哪一列、目标序列读成了什么。

## 热键

| 键 | 作用 |
|---|---|
| `F8` | 一键识别（自动判断是哪个界面，然后执行） |
| `F5` | 只跑摩斯码 |
| `F6` | 只跑指纹识别 |
| `F7` | 只跑操作台旋钮 |

- 全部可在界面**「设置」→ 全局热键**里直接改：点一下那一行 → 直接按下新键即可（**不用打字**），按 `Esc` 取消，改完立即生效（不用重启）。
- `F5` / `F6` / `F7` 是「强制指定」：自动判别偶尔认错时，用它们直接指定跑哪一项。
- 支持单键与组合键：`F1~F24`、字母、数字、`Space`、方向键等，可加 `Ctrl` / `Alt` / `Shift`。
- 如果新键已被别的程序占用，界面会红字提示「热键冲突 · 仍为 F8」，并**保留原来能用的键**，不会出现「显示新键但实际没生效」。

## 截图方式

「设置」→「截图方式」可选两种，切换后下一次抓帧立即生效：

| 选项 | 适用场景 |
|---|---|
| `Windows Graphics Capture`（默认） | 微软官方采集接口（Xbox Game Bar 同款），能截无边框窗口与绝大多数游戏画面 |
| `兼容模式` | 走 GDI BitBlt。某些老游戏或远程桌面下更稳，但**可能截不到独占全屏** |

- 下方「测试截图 → 抓一帧」可以当场验证当前后端能不能出图，会显示缩略图和 `宽×高 · 耗时`。
- **不会后台实时截屏**：只有你按热键、点按钮或点「抓一帧」时才抓，单次识别最多 20 张。

## 窗口与置顶

- 默认**不置顶**，可以被游戏盖住、挂在后台。
- 标题条右侧的 `□` 是图钉：点一下变 `■` 并置顶，再点取消。状态会记住。
- 独占全屏的游戏会盖住任何置顶窗口，这是系统行为，不是程序失效。

## 为什么不再需要微信

原版靠微信自带的 OCR 读角色名。新版改成两条腿走路：

1. **模板投票**（主）：把屏幕上 9 个指纹格拿去和 54 张模板比，哪个角色的模板能同时解释最多格子，就是当前角色。约 5ms，比 OCR 更快更稳。
2. **系统 OCR**（兜底）：Windows 自带的中文 OCR 引擎（`C:\Windows\OCR\zh-cn`），零体积、不联网、不装模型。

顺带一个发现：**每个角色的模板张数就等于该角色的游戏模式**（埃德温 4 张 = 4 号模式，格赫罗斯 8 张 = 8 号模式）。所以模式不用读数字，认准角色就知道了 —— 原版那一步 OCR 是多余的。

## 从源码构建

```bash
# 需要 Rust 1.95+ 与 MSVC 工具链
cargo build --release
# 产物：target/release/delta-pwd-tool.exe
```

体积相关的 profile 已调好：默认 `opt-level="z"` 压体积，但 `delta-vision`/`delta-templates`/`egui` 等热路径单独开 `opt-level=3` 保速度。

> 注意：`panic="abort"` 会让 `cargo test --release` 不可用，测试请用默认 profile。
> `lto` 用的是 `thin` —— 实测 `fat` + `codegen-units=1` 在本机链接阶段会卡死 39 分钟无产出。

## 架构

```
crates/
  geom        百分比坐标 ↔ 像素（幂等换算，越界报错）
  config      配置读写（只存百分比、原子写、防二次缩放漂移）
  capture     GDI 截屏（常驻 DC 复用，黑帧检测）
  vision      纯图像算法（手写 NCC、Otsu、外轮廓、LED 点阵、斜纹检测）
  templates   角色库 + 全模板投票 + 二分图最大权匹配
  input       SendInput（相对小步拖动、Drop 兜底松键、事件计数）
  hotkey      RegisterHotKey 专用线程（免管理员）
  ocr         Windows.Media.Ocr（MTA 单例常驻线程）
  scene       场景结构特征判别（Morse / Fingerprint / Console / Unknown）
  flow-morse          摩斯流程
  flow-fingerprint    指纹流程
  flow-console        操作台旋钮闭环状态机
  ui          egui 界面 + 校准向导
  app         装配、单实例、热键分发、找窗激活
```

设计要点：

- **零 OCR 模型**，不依赖任何外部运行库
- **HOG-free 结构特征**判别场景，分辨率无关，不用整屏模板匹配
- 操作台的灵敏度、方向、切列方式**全部运行时自举**，不写死像素常数
- 上游 3 个缺陷已修：`[0]` 静默降级成 4 模式、失败分支无日志、配置重复加载坐标漂移
- 冻结规格：[`docs/spec/spec.md`](docs/spec/spec.md)（实现工单见 `docs/spec/tickets/t1..t9.md`）
